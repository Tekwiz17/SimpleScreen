# SimpleScreen 1.2.0

- App & Folder Launcher: real macOS icons, searchable app/folder picker, Spotlight folder search, Browse fallback, custom labels, reorderable items, and adjustable grids.
- Now Playing: Music and Spotify track details and playback controls, with explicit opt-in Automation access.
- Browser audio: Safari, Chrome, Edge, and Brave current-tab HTML5 media, with play/pause and ten-second seek controls. Requires Automation and Allow JavaScript from Apple Events; some sites are unsupported.
- Search across widgets, wallpaper styles, palettes, and settings. Widget search understands terms such as apps, folders, music, and browser.
- Updates page: check GitHub releases, read improvements, and download, verify, install, and restart. Manual fallback when the installed location is not writable.
- 29 widget types; existing settings remain compatible.
- Expanded checks for search, versions, release URLs, checksums, archive paths, media data, browser controls, and preparation of the actual release archive.

Requires macOS 14 or later. Universal Apple silicon + Intel. Ad-hoc signed, not notarized. Download and install this release manually once to get the new updater.
