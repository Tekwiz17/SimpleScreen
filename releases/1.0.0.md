# SimpleScreen 1.0.0

A little more you: an open-source wallpaper and widget studio for macOS 14+.

- Five animated procedural wallpaper styles, eight palettes, custom colors, and image/GIF import.
- Eight customizable desktop widgets, grid snapping, saved layouts, and display selection.
- Interactive weather effects and isolated HTML widgets.
- Opt-in local Codex and Claude Code usage snapshots.
- Dock/menu bar visibility, launch at login, and energy-aware motion.

Universal Apple silicon + Intel build. Ad-hoc signed; no paid developer membership required. **Not notarized**: macOS may require Privacy & Security → Open Anyway after your first launch attempt.

Unzip and move SimpleScreen.app into Applications. SHA256SUMS.txt verifies the ZIP.

AI readings require setup and reflect the last recorded provider snapshot. Glass uses native macOS backdrop blur. Weather needs an internet connection and configured coordinates. Read the repository guides for details and limitations.
